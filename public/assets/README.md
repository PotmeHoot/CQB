# CQB Prototype Asset Dimensions

Recommended source dimensions for future art replacement:

- Backgrounds: 1920x1080
- Character full-body: 1024x1536
- Character portraits: 512x512
- Character team cards: 640x800
- Weapon showcase: 1024x512
- Weapon square cards: 1024x1024
- Sidearm showcase: 800x400
- Gadgets: 512x512
- Mission thumbnails: 1280x720
- UI icons: SVG
- Tactical markers: SVG or 128x128

The current prototype uses simple local SVG placeholders only.
